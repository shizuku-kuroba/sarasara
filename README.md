# さらさら

可部署至 GitHub Pages 的純前端字帖工作室。文字、字型和 PDF 都在使用者瀏覽器處理，沒有後端、追蹤器或外部字型 CDN。

## 本機使用

需要 Node.js 22 或以上。

```sh
npm ci
npm run dev
```

## 正式建置與部署

```sh
npm test
npm run build
```

產物為 `dist/`。Vite 使用相對資源路徑，同時支援 `username.github.io` 與 `username.github.io/repository/`。請透過 HTTP 伺服器開啟，不要直接雙擊 HTML。

確認後將本專案目錄推至 GitHub repo 的 main 分支，再在 Settings → Pages 將 Source 設為 GitHub Actions。已附部署 workflow；本次尚未建立遠端或推送。

## 功能

- 米字、田字、方格、九宮、英文四線、點陣、無格線。
- 繁體中文、日本語、韓文、古典英文、哥特體；自訂字型上傳及支援瀏覽器的 Local Font Access。
- 描紅、逐字臨摹、完整範字、空白練習紙。
- A4 / A5 / Letter、橫直紙張、橫排與右至左直排、自動分頁。
- 獨立字體大小、字距、行高（橫線類）、行距、隨字體大小等比例調整的方格、邊界、格線粗細、濃度、文字／格線／紙色。
- 標題、日期欄位、頁碼、重複次數、段後留白。
- 預覽縮放、300 DPI PDF、匯出進度、設定 JSON 匯入匯出及本機自動儲存。

## 已知界線

- PDF 為 300 DPI 點陣影像，不是可選取的向量文字；可保留自訂字型的外觀。
- 上傳字型為頁面生命週期內有效，重新載入後回到內建字型；JSON 不包含字型檔。
- 本機字型讀取依瀏覽器支援及使用者授權；不支援時使用檔案上傳。
- 主要針對中日韓及拉丁文字，尚未提供阿拉伯文／希伯來文的 RTL 段落控制、注音或筆順。
- 英文四線每段一行，過長會縮小；建議手动換行。最多 6,000 字元、一次 PDF 至多 80 頁。
- 本機自動儲存包含輸入文字，可在「使用說明」清除。
- 內建字型皆隨站點部署，授權位於 `public/licenses`。

## 第二版介面

- 範例只替換文字，不修改字型、格線和標題。
- 練習模式有圖示與說明；進階選項分組收合。
- 全頁預覽同時依紙張方向與容器寬高縮放。
- 英文四線停用直排、非描紅模式停用濃度，說明適用條件。
- 步驟淡入位移、選取線條、紙張更新淡入、按鈕回饋、匯出進度；尊重 prefers-reduced-motion。
- 鍵盤切換步驟後焦點移到新章節標題。

第二版已實際操作四步切換、英文格線相依設定與 PDF 成功狀態，並查看 390px 手機版。未推送或公開部署。

## 語言、TXT 與範例庫

第一步先選語言：中文預設米字格／思源宋體，英文預設四線／Cormorant，日文與韓文預設方格與對應字型。切換語言保留原文，套用新語言建議字型、格線及橫排；格線選單優先顯示對應語言選項，也可展開其他格線。

TXT 匯入支援 UTF-8、UTF-16 BOM 偵測，以及手動 Big5、UTF-16 LE/BE。檔案上限 1 MB、內容上限 6,000 UTF-16 碼元；先預覽，選擇替換或附加，提供一次文字復原。不會靜默截斷過長內容或接受二進位資料。

內建 18 段範例，以語言、類別及篇名／作者搜尋。包括唐詩、李叔同〈送別〉節選、William Blake、Shakespeare sonnets、Jane Taylor、日韓字母及原創練習短句。公版原文與來源連結收於 `src/content-library.js`；現代歌曲類別提供使用者自行匯入／貼上入口，未內建受保護的現代歌詞。

英文新增斜線輔助格（45–80 度，相對水平線），使用相同 Canvas 流程預覽及匯出 PDF；英文在無格線／點陣模式仍按整行排列。

驗證：16 項自動測試通過，正式建置成功；實際測試 TXT 預覽、套用、復原、語言預設、莎士比亞分類及來源、斜線格 PDF 成功狀態。使用獨立 localhost 測試頁，保留使用者 127.0.0.1 頁面的編輯內容。

## 紙張背景、固定範例視窗與獨立重複

紙張改以四類瀏覽：方格（方格／米字／田字／九宮）、橫線／書法（一般橫線／英文四線／西洋書法）、點陣、空白。所有語言都能瀏覽全部類別；語言只決定起始預設。

範例庫擴至 24 段，新增宮澤賢治〈雨ニモマケズ〉、《銀河鉄道の夜》，以及 Alice’s Adventures in Wonderland、Pride and Prejudice、A Tale of Two Cities、Moby-Dick 節選。保留原文來源，省略振假名或調整練習換行時明確標示。

範例視窗採固定 viewport-relative 寬高，列表與預覽內部捲動。實測桌面切換短詩、長文及自行匯入狀態均為 820 × 648px（當時視窗尺寸）；390px 手機上外框 354 × 759.6px，內容沒有撐高外框。

重複規則：先對非空白的 grapheme cluster 套用 `charRepeat`，再以每個輸入行為一組重複 `lineRepeat`（若自動換行，整組一起重複），最後加段後空白行。兩種次數都包含原文。啟用 `fillPage` 後，依目前設定循環練習內容，填滿最後一頁。方格臨摹每字成一練習行，按字重複次數擺範字後補空格；橫線臨摹每行範字後附一行空白，整組重複。直排時練習行對應直欄。舊 JSON/localStorage 的 `repeat` 會按原格線映射為字或行重複。

目前 25 項自動測試通過，正式建置成功，已實際檢查紙張分類、一般橫線、2 次字 × 3 次行的畫面，以及桌面／手機固定範例視窗。尚未推送 GitHub。
